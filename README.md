# SC Fast View

عارض رسومات **DXF** سريع وواضح على الأندرويد — من غير إعلانات.

## إيه ده؟

تطبيق أندرويد بيفتح ملفات DXF (رسومات أوتوكاد) ويعرضها بسرعة ووضوح:
- تكبير وتصغير وسحب بإصبعك (Pinch to zoom)
- قايمة طبقات — إظهار وإخفاء أي طبقة
- قياس مسافة بين نقطتين
- دوس على أي عنصر تعرف نوعه وطوله وطبقته
- فاتح وغامق
- آخر الملفات اللي فتحتها
- رسمة تجريبية جاهزة (شقة) للتجربة من غير ملف

## ملفات DWG

التطبيق بيفتح **DXF** مباشرة. ملف **DWG** لازم يتحول DXF الأول — خطوة واحدة مجانية:
من أوتوكاد: **Save As ← DXF**، أو أي محوّل مجاني DWG to DXF، وبعدها افتحه في التطبيق.

## التثبيت (APK)

1. افتح صفحة **Actions** في الريبو ده.
2. اختار آخر تشغيل ناجح لـ **Build APK**.
3. حمّل ملف **sc-fast-view-apk** من قسم Artifacts.
4. فك الضغط وثبّت ملف الـ APK على موبايلك (هتحتاج تسمح بالتثبيت من مصادر غير معروفة مرة واحدة).

## البناء

المشروع مبني بـ [Capacitor](https://capacitorjs.com/) — واجهة ويب (HTML/CSS/JS) جوه تطبيق أندرويد أصلي.

```bash
npm install
npx cap sync android
cd android && ./gradlew assembleDebug
```

الـ APK بيتبني أوتوماتيك على GitHub Actions مع كل Push على `main`.

## الملفات

- `www/` — التطبيق (عارض DXF)
  - `dxf.js` — محلل ملفات DXF
  - `app.js` — العرض والتفاعل
  - `demo.dxf` — رسمة تجريبية
- `android/` — مشروع الأندرويد
- `.github/workflows/build-apk.yml` — بناء الـ APK على GitHub
